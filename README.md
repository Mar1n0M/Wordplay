# WordPlay
A web game that utilizes a puzzle-like structure to make language learning fun and addictive.
## Features
- **Custom sentence packs with distractors** – add original sentences, word‑by‑word translations (with optional positioning requirements), and distractors.
- **Export/Import JSON sentence packs** – share your packs or use those made by others.
- **Smart repetition** – words you find difficult appear more often (weighted randomness).
- **Dark mode** – toggle and preference is saved automatically.
- **Streak & scoring** – +20 points for a correct answer, –10 for a wrong one; milestones at 100, 500, 1000 points. When you wish to end a session, you can get your stats.
## How to use
1. **Add sentences** by creating your own pack or importing it.  
2. **Start playing** when you are done with the first step.
3. **Click words** in the bank to place them → **Check** → get feedback and points.
4. **Hint** button can be used to highlight a missing word (max 2 per sentence).
5. Use **End session** to see your stats and reset the scoreboard.
